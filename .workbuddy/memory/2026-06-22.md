# 2026-06-22

## oar-ocr-web 项目创建

基于 oar-ocr v0.7.1 创建了兼容 PaddleOCR Serving API 的 Web 服务。

### 完成内容
- **后端**: Axum 0.7 + oar-ocr (PP-OCRv6 small) + auto-download 模型
- **API**: POST /api/ocr (multipart/form-data), GET /api/health, 兼容 PaddleOCR Serving 响应格式
- **前端**: 拖拽上传 + Canvas 检测框可视化 + 文字列表 + 置信度 + 一键复制
- **Docker**: 多阶段构建 (rust:1.95-bookworm → debian:bookworm-slim), docker-compose.yml
- **编译**: cargo check 通过

### 关键文件
- `src/main.rs` — Axum 服务入口
- `src/ocr_engine.rs` — OCR 引擎初始化 (PP-OCRv6 small)
- `src/routes/mod.rs` — API 路由 + multipart 解析
- `src/types.rs` — PaddleOCR 兼容类型
- `src/error.rs` — 统一错误处理
- `static/` — 前端三件套
- `Dockerfile` + `docker-compose.yml` — 容器化部署

### 模型
- 检测: pp-ocrv6_small_det.onnx (~9.4MB)
- 识别: pp-ocrv6_small_rec.onnx (~20MB)
- 字典: ppocrv6_dict.txt (~73KB)
- auto-download 自动从 ModelScope 下载到 OAR_HOME (~/.oar/)

### 启动方式
- 本地: `cargo run --release`
- Docker: `docker compose up -d`
- 端口: 3000 (可通过 PORT 环境变量覆盖)
